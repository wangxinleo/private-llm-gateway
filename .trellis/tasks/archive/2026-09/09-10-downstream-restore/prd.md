# 下行无感还原:SSE 流式响应占位符实时还原

## Goal

模型回复经过本地网关时,自动对照映射表把脱敏占位符还原为真实明文,SSE 流式实时还原、打字机体验不受影响;非流式 JSON 响应同样还原。作为脱敏/还原闭环再评审的载体,修复"只脱敏、不还原"的设计缺陷。

## Background / 已确认事实(代码实证)

- 上游脱敏链:`runPipeline`(src/scanner/pipeline.ts:16)→ `applyMasks`(src/scanner/pii.ts:77)用 `replaceAll(matched, maskTag)` 替换;json-mask.ts:55 有第二处内联 replaceAll。
- 占位符由 `buildMaskTag`(src/scanner/mask-tag.ts)生成,生产点 3 处:pii.ts:65、secrets.ts:117、context-key.ts:411。
- **缺陷**:同类别所有值映射到同一占位符 `<<PRIVACY_MASK:CATEGORY>>`,无唯一实例 ID、无映射表,回复无法精确还原。
- SSE 为哑流式透传(src/proxy/streaming.ts),分块可能把占位符截断在任意字节边界;非 SSE JSON 原样放行(route.ts:254)。
- `Finding.matched` 保留原始值,存在于请求作用域 → 每请求内存映射即可,无需持久化。
- 审计 `logAudit`(route.ts:204)先于转发,还原天然发生在审计之后。

## 已裁决决策

| # | 决策 | 结论 |
|---|------|------|
| D1 | 占位符格式 | **语义紧凑格式(v3.1,maskit 借鉴)**:`{{CODE_SUF5}}`(如 {{PHONE_TRWMQ}});类别短码白名单(≤12 字符)+ 每值**随机纯辅音后缀**(绝不从原文哈希派生:防猜测-验证 Oracle 与十六进制算术诱导,maskit 生产实证);旧 explicit/v2 与 legacy 只读识别,未命中原样放过 |
| D2 | 还原范围 | 全文本字段统一还原:响应中出现占位符即还原,覆盖正文、tool 参数、reasoning,不做字段白名单 |
| D3 | 映射生命周期 | 每请求内存映射,值级去重(同值同占位符);不做跨请求持久化 |
| D4 | 消歧提示词 | **v3 重裁:条件注入极简保真指令**。仅当发生脱敏(registry 非空)且 `PRIVACY_DISAMBIGUATION_MODE=auto`(默认)时注入一行指令(无原文);off 等效旧"彻底删除"决策,秒级可回退。沿革:先彻底删除 → 主流对比显示与业界全体相反 → 重评审后改为受控注入 |

## Requirements

- R1. 每个屏蔽实例生成唯一映射(占位符 ↔ 原文一一对应),支持无歧义还原。
- R2. 网关下行对模型回复自动还原:命中映射表的占位符还原为真实明文。
- R3. SSE 流式实时还原:占位符可跨任意 chunk 边界(含单字节切分与 **delta 事件切分**——事件层通道化还原保证拼接),增量处理、不缓冲至流结束,打字机体验不受影响。
- R4. 非 SSE JSON 响应还原后再返回;还原作用于全文本字段(统一字符串替换,不做字段白名单)。
- R5. 未命中映射的占位符与无关文本原样放过;不崩溃、不吞流、不引入可感知延迟。
- R6. 还原发生在审计之后、响应边界;审计仍为脱敏语义。
- R7. 旧格式只读兼容:还原器同时识别 v3 语义格式、旧 explicit(`<<PRIVACY_MASK:CAT[:N]>>`)与 legacy(`[CATEGORY]`);仅映射命中的还原,其余透传;`PRIVACY_MASK_FORMAT=legacy` 下还原不启用(同类别多值无歧义还原不可能)。
- R8. 同一请求内相同原始值映射到相同占位符(值级去重);后缀为密码学随机 5 位纯辅音(字符集 bcdfghjkmnpqrstvwxz),**绝不从原文哈希派生**(确定性后缀构成上游猜测-验证 Oracle,maskit 借鉴),冲突时请求内重掷,保证占位符 ↔ 原文严格双射。
- R9. 极简保真指令(D4 v3):默认文案压缩为一行(禁止展开/伪造/改写/删除占位符,不含原文),复用既有协议感知注入点(system/developer/instructions/Gemini system_instruction);`PRIVACY_DISAMBIGUATION_MODE` 收敛为 auto|off(默认 auto,旧值 prefix/json-meta 解析为 auto 兼容)。
- R10. 安全不变式(原文绝不出网):发往上游的请求载荷中,任一被脱敏原文的出现次数恒为 0;指令文案不含任何原文;审计与日志仅含占位符。
- R11. 保留字防误伤 + 防套娃:用户原文中已存在符合占位符文法的文本(如模板代码 {{X_1234}})不参与还原替换;未被映射命中的同形文本一律透传;原文自身命中占位符文法时严禁二次包裹——反查映射还原真值,查不到原样保留(maskit 借鉴)。
- R12. 宽松修复兜底(maskit 借鉴):模型剥落花括号的残缺形态(如 SECRET_TRWMQ)仅当查得映射时修复还原,并计入 degraded 独立指标;查不到原样透传,绝不猜测未签发的同形文本。

## 用户故事

- US-1 单轮多敏感值:一次发送多个手机号/密钥,回复中各自精确还原,不串值。
- US-2 SSE 打字机:占位符被任意切分,输出平滑连贯,无感知还原存在。
- US-3 多轮对话:客户端每轮回传完整历史(真实明文),网关每轮重建映射,回复引用历史占位符仍可还原。
- US-4 非流式 JSON:`stream:false` 调用方拿到的 JSON(含 tool_calls 字段)已全量还原,可直接解析消费。

## 验收标准

- [ ] AC1 多值不串:同请求多个同类别/跨类别敏感值,回复占位符一一精确还原。
- [ ] AC2 跨 chunk 还原:占位符按前缀/中间/尾部任意切分(含单字节、跨 UTF-8 序列、**跨 delta 事件边界**),流式还原输出与全量还原一致;假前缀(如 `{{PHONE_FAKE}}` 文法失配、模板代码 `{{ user.name }}`)判定失败后立即顺序释放,不丢字、不死等。
- [ ] AC3 未命中透传:幻觉占位符(如 {{EMAIL_TRWMQ}} 文法合法但映射缺席)、旧格式无映射标签原样透传,不抛异常不阻断。
- [ ] AC4 非流式还原:`stream:false` JSON 响应(含 `tool_calls[].function.arguments` 内占位符)还原且 JSON 结构有效。
- [ ] AC5 审计隔离:审计记录仅含占位符;还原在审计之后。
- [ ] AC6 流异常:上游中断/客户端 Abort 时,已还原内容不回滚,缓冲区有效文本 flush 后安全关闭。
- [ ] AC7 回归:现有扫描/阻断/绕过/多模态/审计测试全绿;占位符格式变更后相关断言同步更新。
- [ ] AC8 指令注入门控:脱敏请求(auto 模式)转发体含恰好一条极简保真指令;未脱敏请求与 off 模式转发体零注入;指令文案不含任何原文。
- [ ] AC9 上游零泄漏:mock 上游捕获的请求载荷中,所有被脱敏原文的出现次数为 0(占位符替换完整覆盖 body 字段与文件文本)。
- [ ] AC10 宽松修复:花括号剥落形态(如 SECRET_TRWMQ)查表修复并计入 degraded 独立指标;未签发的同形文本不误伤、不猜测。

## 边界与异常场景

- 假前缀回退、流尾悬挂前缀 EOF flush、占位符无缝拼接、Markdown/代码块内还原、嵌套畸形占位符单遍处理不递归。
- 并发请求映射表相互隔离(Request Scope);请求完成/断开/超时后映射随之回收。
- 同一原始值跨类别(如手机号出现在 DB_URI 内)由既有 longer-match 去重收敛;注册表键含类别,不冲突。
- 上游 4xx/5xx 错误体回显占位符按同规则还原。
- 伪造占位符洪泛:单遍线性匹配,无灾难回溯。
- 用户模板文本撞形(JS/Handlebars 的 {{...}}):文法不匹配或映射未命中即透传;与占位符同形的用户原文在扫描期登记保留,不生成相同占位符。
- 十六进制后缀算术诱导(maskit 生产实测:模型把 {{IPPRIVATE_83fc6a}} 当网段拆算,自造派生 token):后缀改纯辅音随机串,消除数值可读性。
- 模型剥落花括号({{...}} 是模板语法,模型写命令/代码时顺手整理):R12 宽松修复查表兜底,degraded 单独计数可观测。

## 非目标

- 跨请求/长会话映射持久化;客户端侵入式 SDK;对原文值的模糊容错匹配(拼写变异不纠错;花括号残缺的结构性修复属 R12,非模糊匹配);审计明文反查;传输加密扩展。
